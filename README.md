# فروشگاه آلبالو

یک فروشگاه اینترنتی فارسی (راست‌به‌چپ) با **بک‌اند واقعی، پایگاه داده، احراز هویت، CMS و پنل‌های نقش‌محور**.
هیچ بسته‌ی خارجی لازم نیست (`npm install` ندارد): فقط Node.js نسخه‌ی ۲۲٫۱۳ یا بالاتر.

## اجرا

```bash
npm start
```

سپس `http://127.0.0.1:3000` را باز کنید. در اولین اجرا، پایگاه داده (`data/shop.db`) ساخته و با داده‌ی نمونه پر می‌شود.

| دستور | کار |
|---|---|
| `npm start` | اجرای سرور |
| `npm run dev` | اجرا با راه‌اندازی مجدد خودکار هنگام تغییر |
| `npm run seed` | پاک‌سازی همه‌ی داده‌ها و ساخت دوباره‌ی داده‌ی نمونه |
| `npm test` | اجرای آزمون‌های API (۲۱ آزمون: نقش‌ها، CSRF، سفارش، موجودی، …) |

## حساب‌های آزمایشی (فقط توسعه‌ی محلی)

| نقش | ایمیل | گذرواژه |
|---|---|---|
| مدیرکل | `admin@albaloo.test` | `Admin@12345` |
| مدیر فروش | `manager@albaloo.test` | `Manager@12345` |
| ویرایشگر محتوا | `editor@albaloo.test` | `Editor@12345` |
| مشتری | `customer@albaloo.test` | `Customer@12345` |

این حساب‌ها در حالت `NODE_ENV=production` **ساخته نمی‌شوند** (پایین‌تر را ببینید).

داشبوردها: مشتری (خلاصه‌ی خرید)، مدیر فروش (فروش ۱۴ روز، سفارش‌های در انتظار، موجودی کم)، ویرایشگر (آمار محتوا و نظرهای در انتظار)، مدیرکل (هر سه + کاربران و فعالیت‌ها).

## امکانات

**فروشگاه:** فهرست با فیلتر دسته، جستجوی فارسی، مرتب‌سازی و صفحه‌بندی · صفحه محصول با مشخصات و نظر خریداران · سبد خرید (قیمت‌ها را سرور حساب می‌کند) · کد تخفیف · پرداخت در محل · ثبت سفارش فقط برای کاربر واردشده · وبلاگ و صفحه‌های ثابت.

**احراز هویت:** ثبت‌نام مشتری، ورود، خروج · گذرواژه با scrypt · نشست سمت سرور با کوکی `HttpOnly` · محدودیت تلاش ورود · تغییر نقش یا غیرفعال‌سازی، نشست‌های کاربر را فوراً باطل می‌کند.

**CMS:** ساخت و ویرایش صفحه و مقاله با ویرایشگر مارک‌داون و پیش‌نمایش · پیش‌نویس/انتشار · تصویر شاخص · نامک · پیوند صفحه‌ها در پایین سایت.

**مدیریت فروش:** محصولات (تصویر، قیمت، تخفیف، موجودی، مشخصات) · دسته‌بندی‌ها · سفارش‌ها با مسیر وضعیت مجاز (انتظار ← آماده‌سازی ← ارسال ← تحویل، یا لغو با بازگشت موجودی) · کدهای تخفیف (درصدی/ثابت، حداقل خرید، سقف استفاده، انقضا) · نظم‌دهی نظرها.

## ساختار پروژه

```
server/
  index.js, app.js     راه‌اندازی، مسیریابی، هدرهای امنیتی، فایل‌های ایستا
  db.js                شِمای SQLite (node:sqlite) و ابزار کوئری
  auth.js              گذرواژه، نشست، دسترسی، محدودیت تعداد
  constants.js         نقش‌ها، دسترسی‌ها، وضعیت‌ها، تنظیمات پیش‌فرض
  shop.js              قیمت‌گذاری سبد، کد تخفیف، سریال‌سازی
  seed.js              داده‌ی اولیه
  routes/              auth، public، account، admin-*
public/
  index.html, css/     پوسته و استایل
  js/                  app (مسیریاب)، store، cart، auth، panel، core، shared
test/api.test.js       آزمون‌های API
data/                  پایگاه داده و تصویرهای بارگذاری‌شده (در git نیست)
```

## نصب روی سرور (production)

```bash
NODE_ENV=production ADMIN_EMAIL=you@example.com ADMIN_PASSWORD='یک-گذرواژه-قوی-حداقل-۱۰-نویسه' npm start
```

- در حالت production، به‌جای داده‌ی نمونه فقط **یک مدیرکل** با همین ایمیل و گذرواژه ساخته می‌شود (حداقل ۱۰ نویسه).
- پشت یک پراکسی **HTTPS** (مثل Nginx یا Caddy) اجرا کنید. کوکی نشست در production به‌صورت `Secure` ارسال می‌شود (`COOKIE_SECURE=0` فقط برای آزمایش روی HTTP).
- پشت پراکسی، `TRUST_PROXY=1` بگذارید تا نشانی IP واقعی برای محدودیت ورود خوانده شود.
- متغیرهای دیگر: `PORT` (پیش‌فرض ۳۰۰۰)، `HOST` (پیش‌فرض `127.0.0.1`)، `DATA_DIR`، `DB_PATH`.
- از پوشه‌ی `data/` (پایگاه داده و `uploads/`) نسخه‌ی پشتیبان بگیرید.

## امنیت (آنچه پیاده شده)

سرور همه‌ی قیمت‌ها و موجودی را دوباره حساب می‌کند · اعتبارسنجی همه‌ی ورودی‌ها · توکن CSRF برای هر درخواست تغییردهنده + بررسی `Origin` · CSP و هدرهای امنیتی · متن مقاله‌ها بدون اجرای HTML نمایش داده می‌شود · بارگذاری فقط تصویر واقعی (بررسی محتوا، بدون SVG) · محافظت در برابر پیمایش مسیر · هر مشتری فقط داده‌ی خودش را می‌بیند.

## آنچه هنوز نیست

- **درگاه پرداخت آنلاین** (مثل زرین‌پال): فعلاً فقط پرداخت در محل. نقطه‌ی اتصال، ثبت سفارش در `server/routes/account.js` است.
- **ایمیل/پیامک** (بازیابی گذرواژه، اطلاع‌رسانی سفارش): نیازمند یک سرویس‌دهنده‌ی ایمیل یا پیامک است. فعلاً مدیرکل می‌تواند گذرواژه‌ی کاربر را بازنشانی کند.
- مقیاس چندسروری: پایگاه داده SQLite و محدودکننده‌ی تلاش‌ها در حافظه‌ی یک سرور هستند.
